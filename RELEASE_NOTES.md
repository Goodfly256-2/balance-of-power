**Balance of Power v1.7.0** — стратегия реального времени на pygame.

## Что нового

- **Название** теперь только на английском: Balance of Power
- **Фронтовые числа** — только у пар стран, которые воюют между собой:
  мирные границы больше не подписываются
- **Донат** в главном меню (вкладка «Поддержать»): USDT / USDC / POL
  в сети Polygon, копирование адреса в один клик
- **Установщик Windows**: BalanceOfPower-Setup-1.7.0.exe — запуск без Python;
  `BalanceOfPower.exe` — переносимая версия (один файл)
- README и лицензия MIT — код полностью открыт

## Установка

1. Скачайте `BalanceOfPower-Setup-1.7.0.exe` ниже.
2. Запустите и следуйте мастеру (можно поставить без прав администратора).
3. Игра сама сгенерирует музыку и экраны загрузки при первом запуске.

Полный список изменений — в [CHANGELOG.md](https://github.com/Goodfly256-2/balance-of-power/blob/master/CHANGELOG.md).
